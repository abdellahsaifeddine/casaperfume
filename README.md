# casaperfume

Site web e-commerce pour parfums.

## Description
Site simple pour présenter et commander des parfums pour homme et femme.

## Technologies
- HTML
- CSS
- JavaScript

## Structure du projet
- `index.html` : page principale
- `pages/` : pages produits et commandes
- `css/` : styles
- `js/` : scripts
- `images/` : images utilisées

## Comment lancer
Ouvrir `index.html` dans un navigateur.
